# S01E09 — Wi‑Fi public : les bons réflexes

Un réseau gratuit peut coûter cher… si tu t’y connectes les yeux fermés.

## 1. Pratique, mais pas sans risque
Le Wi‑Fi public peut être utile dans un café, une gare, un hôtel ou un lieu de passage.
Mais sur un réseau partagé, tes données peuvent être moins bien protégées, surtout si tu te connectes sans vérifier.

## 2. Les pièges
Tous les réseaux gratuits ne sont pas fiables.

### A. Faux réseau
Un nom rassurant ne prouve rien.

### B. Pas de cadenas
Évite les actions sensibles si tu n’es pas sûr du site.

### C. Trop d’infos
Ne donne que le strict nécessaire.

## 3. Les bons réflexes
Avant de te connecter, prends quelques secondes pour vérifier :
1. Je demande le bon nom du réseau au personnel ou je le vérifie sur place.
2. Je coupe le partage automatique et la connexion auto quand je n’en ai pas besoin.
3. Je préfère les sites et applis sécurisés, avec le cadenas HTTPS.
4. J’évite la banque, les achats ou les documents sensibles sur un Wi‑Fi public.
5. Si possible, j’utilise mes données mobiles ou un VPN de confiance.

## 4. En résumé
- Gratuit ne veut pas dire sans risque.
- Je vérifie le bon réseau avant de me connecter.
- Je limite ce que je fais sur un Wi‑Fi public.
- Un doute = je m’abstiens.

## Le savais-tu ?
Un faux réseau Wi‑Fi peut imiter le nom d’un vrai point d’accès pour te pousser à t’y connecter sans te méfier.

## Le conseil d’Octet
Le meilleur réflexe : vérifier avant de cliquer… et avant de se connecter !
