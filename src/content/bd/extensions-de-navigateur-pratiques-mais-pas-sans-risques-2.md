# S01E08 — Extensions de navigateur : pratiques, mais pas sans risques

Les extensions peuvent nous simplifier la vie… ou nous la compliquer !

## 1. À quoi elles servent
Les extensions peuvent ajouter des fonctions utiles à ton navigateur :
- bloquer les pubs ;
- gérer les mots de passe ;
- traduire une page ;
- comparer les prix.

## 2. Les risques
Mais attention : toutes les extensions ne sont pas fiables.
Certaines peuvent :
- lire tes pages et tes données ;
- collecter trop d’informations ;
- afficher des publicités ;
- te suivre ;
- être malveillantes.

## 3. Les bons réflexes d’Octet
- Installe uniquement des extensions depuis les boutiques officielles.
- Vérifie la note et le nombre d’avis.
- Regarde les autorisations demandées : si c’est trop, méfiance.
- Supprime les extensions que tu n’utilises plus.
- Garde ton navigateur à jour.

## 4. Exemple : une extension malveillante
Une fausse extension peut promettre des cadeaux ou une fonction magique.
En réalité, elle peut :
- lire tes pages visitées ;
- récupérer tes données ;
- afficher des pubs.

## En résumé
- Utilise des extensions officielles et fiables.
- Vérifie les avis et les autorisations.
- Moins tu en as, mieux c’est.

## Le sais-tu ?
Certaines extensions peuvent te suivre même quand tu ne les utilises pas.

## À toi de jouer
Fais le tri dans tes extensions aujourd’hui :
enlève celles dont tu n’as plus l’utilité
et vérifie que les autres sont toujours dignes de confiance.
