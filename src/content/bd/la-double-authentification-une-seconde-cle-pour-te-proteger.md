# S01E02 — La double authentification : une seconde clé pour te protéger !

Salut ! Moi c’est Octet, le singe du numérique.

Aujourd’hui, je t’explique la double authentification.

## 1. Pourquoi c’est important ?
Si quelqu’un découvre ton mot de passe, il peut essayer de se connecter à ta place. La double authentification ajoute une seconde vérification qui peut bloquer l’accès.

L’action : active la double authentification sur tes comptes importants.

## 2. C’est quoi exactement ?
En plus de ton mot de passe, on te demande un second élément pour vérifier que c’est bien toi : téléphone, application d’authentification, passkey ou clé de sécurité.

## 3. Comment ça fonctionne ?
Après ton mot de passe, une seconde vérification est demandée : passkey, application d’authentification, clé de sécurité, notification ou code temporaire.

## Quelle méthode choisir ?
Privilégie une passkey ou une clé de sécurité lorsqu’elles sont proposées. Une application d’authentification est également une bonne solution. Le SMS reste préférable à l’absence de double authentification, mais il est moins sécurisé.

## 4. Fais-le maintenant
1. Ouvre les paramètres de sécurité de ton compte.
2. Active la double authentification.
3. Choisis une passkey ou une application d’authentification si possible.
4. Garde tes codes de récupération en lieu sûr.

## En résumé
- Un mot de passe protège ton compte.
- La double authentification ajoute une protection supplémentaire.
- Privilégie une passkey, une clé de sécurité ou une application d’authentification.
- Utilise le SMS si aucune meilleure méthode n’est disponible.
- Commence par tes comptes les plus importants.

## Le conseil d’Octet
Commence par la messagerie, la banque, les réseaux sociaux et les achats en ligne.
